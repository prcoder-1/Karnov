# Karnov — реконструкция на C++

Это реверс-инжиниринг PC-порта **Karnov** (Data East USA / Quicksilver
Software / Interactive Designs / Databar, 1987) из оригинального
`KARNOV.EXE` — 16-битного DOS-бинарника, скомпилированного Borland Turbo-C 1987
в compact-модели.

> **🎯 ГЛАВНЫЙ ДОКУМЕНТ ПРОЕКТА**: `PROJECT_SUMMARY.md` — содержит ВСЮ
> важную информацию: декомпиляция AI, форматы файлов, скрытые механики,
> карта sprite ↔ handler, статистика, ссылки на отдельные файлы.

## Статус подсистем

| Подсистема         | Файл                       | Полнота перевода |
|--------------------|----------------------------|------------------|
| RLE I/O (`0x5A`)   | `src/file_io.cpp`          | **полный**        |
| Загрузка `.BIN`    | `src/level.cpp`            | **полный**        |
| Демо `.MOV`        | `src/demo.cpp`             | **полный**        |
| Ввод (клавиатура)  | `src/input.cpp`            | **полный**        |
| Ввод (джойстик)    | `src/input.cpp`            | каркас            |
| Видео-режимы       | `src/video.cpp`            | каркас + диспетчер |
| Спрайты            | `src/sprite.cpp`           | заглушка          |
| Главный цикл       | `src/game.cpp`             | каркас (UPDATELOCS, POSTHITS, DOCONTROLS, ...) |
| Точка входа        | `src/main.cpp`             | каркас            |
| Кредиты, меню      | `src/game.cpp`             | заглушка          |

«Полный» — функция переведена пословно на основе дизассемблирования и читает
оригинальные `LEVEL%d.BIN` / `LEVEL%d.MOV` побайтово совместимо.

«Каркас» — структура и важнейшие функции переведены, но детали (например,
формат вывода в EGA-плоскости) сохранены как комментарии-задокументированные
адреса вызовов.

«Заглушка» — есть тип/прототип и комментарий с адресом в EXE; внутри пусто.

## Сборка

```
cd karnov_cpp
make
```

(Для современных компиляторов нужен C++17. Игра не запустится без графической
подсистемы — это исходный код, а не порт.)

## Ограничения и заметки

1. **Память**: оригинал — compact-модель Turbo-C: маленький `CS` (на самом
   деле в Karnov много кодовых сегментов и far-вызовов), большой `DS`,
   far-указатели на динамические данные. В реконструкции используются обычные
   указатели — структура данных та же, но far/near-различие потеряно.
2. **Графика**: оригинал работает напрямую с памятью видеоадаптера
   (CGA `B800:0`, EGA через регистры `0x3CE/0x3C4`, Tandy `B800:0`,
   Hercules `B000:0`). Реконструкция оставляет точки расширения, но не
   эмулирует адаптер.
3. **Звук**: оригинал использует PC speaker через таймер 8254. В каркасе есть
   заглушки `sound_*`.
4. **Файловый ввод-вывод**: все обращения к диску идут через специальную
   обёртку `bin_fopen()` / `bin_fread()` (см. `file_io.cpp`), которая на лету
   распаковывает RLE-сжатые данные. Это работает абсолютно прозрачно для
   игрового кода.
5. **Не воспроизведено**: точная raster-логика, EGA-планы, аппаратная
   синхронизация по VSYNC, контроллер тайминга. Это поведенческие части,
   а не структурные.
